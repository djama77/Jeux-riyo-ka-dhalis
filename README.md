# Jeux — Riyo ka Dhalis

Jeu traditionnel de Djibouti, deux joueurs, 12 trous et 48 pierres. Projet de sauvegarde patrimoniale et de prototype web.

## Règles documentées
- Deux rangées de six trous, quatre pierres par trou.
- Départ dans un trou non vide de son camp.
- Distribution antihoraire sur les douze trous.
- Si la dernière pierre arrive dans un trou auparavant occupé, reprendre les pierres et continuer.
- Si elle arrive dans un trou auparavant vide, arrêter sans capture et changer de joueur.
- Un camp vide perd immédiatement, y compris pendant le tour adverse.

La disposition graphique exacte et les cas de relais exceptionnels nécessitent des tests de validation.
